Accessible toast notifications for OutSystems

Toasteur is the engine behind the CustomToastNotification component for OutSystems O11 and ODC. It is plain JavaScript and CSS with no dependencies, so this page runs the exact same files the component ships.

  • Screen-reader announcements
  • No focus stealing
  • Pause on hover, focus, hidden tab
  • Bounded queue
  • Deduplication
  • Zero dependencies

Behavior scenarios

    
The cases that usually break toast libraries.

    

      

        
DeduplicationClick repeatedly. The same message reinforces one toast with a counter instead of stacking copies, and it is announced again.

        
      

      

        
QueueFires 8 different toasts. Only MaxVisible show at once; the rest enter as others close.

        
      

      

        
Error in a loopFires 60 different errors at once. The queue is bounded by MaxQueued, so the excess is dropped with a console warning instead of flooding the screen for minutes.

        
      

      

        
PersistentStays until you close it. No auto-dismiss, no progress bar.

        
      

      

        
Tab switchClick, switch to another tab, come back later. The timer paused while the tab was hidden and the toast is still there.

        
      

      

        
Clickable toastA toast with an action. Reachable with Tab and activated with Enter or Space, not only with the mouse.

        
      

      

        
SoundOne toast of each type, each with its own tone. Turns EnableSound on. Use the speaker button on a toast to mute the session.
